## 🛠️ Project

### 1. Password Strength Checker
A Python code that evaluates password strength based on:
- ✅ Minimum length (8+ characters)
- ✅ Uppercase letters
- ✅ Lowercase letters
- ✅ Digits
- ✅ Special characters

The code scans the password character by character and calculates a strength score based on how many criteria are met.

**Concepts used:**
- String iteration
- Character methods (`isupper()`, `islower()`, `isdigit()`, `isalnum()`)
- Conditional logic
- Scoring system
